# Chime design files

Everything here is exported from the working prototype, for dropping into Figma or a deck.

- `screens/` all 23 screens at iPhone 17 Pro resolution (1206 × 2622 px, transparent rounded corners). File names follow the flow: onboarding, report, confirmation, tracker (five stages), closure, notifications, widgets, city map.
- `chime-brand-board.png` logo, colour, type and the wave-to-skyline line. Source: `brand-board.html`.
- `chime-app-icon.png` the app icon (512 px). `chime-mark.png` the mark alone on a transparent background.

## Type

San Francisco (SF Pro) is the typeface. Apple does not license it for the web, so the app's font stack puts SF first (it renders on iPhone and Mac) and falls back to Inter, the closest match, on other devices. The images here were rendered with Inter.

## Colour

Chime Blue `#0866FF`, Sky `#9CC2FF`, Midnight `#0A1030`, Ink `#000000`, White `#FFFFFF`, Mist `#F7F7F8`. The voice gradient runs white, sky, blue, midnight, black.

## Figma

The Figma file still carries the earlier brand. It could not be edited from this session (the account has a View seat). To bring it up to date, drag the PNGs from `screens/` into the file, or give an editing seat and the screens can be rebuilt as editable layers.
